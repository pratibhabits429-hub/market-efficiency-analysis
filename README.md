# Market Efficiency Analysis

## Overview

This project examines weak-form market efficiency using empirical tests of serial dependence in financial returns.

The analysis focuses on return behaviour, autocorrelation and the Ljung–Box test to assess whether historical returns contain statistically significant serial correlation.

## Research Question

Do historical returns exhibit statistically significant serial dependence?

## Methodology

The analysis includes:

- Return calculation
- Descriptive statistics
- Autocorrelation analysis
- Ljung–Box tests
- Statistical significance testing
- Interpretation of empirical results

## Key Results

The estimated first-order autocorrelation was approximately **-0.0206**.

The Ljung–Box test at lag 10 produced a p-value of approximately **0.426**, while the lag-1 test produced a p-value of approximately **0.469**.

The results do not provide statistically significant evidence of serial correlation at conventional significance levels in the analysed sample.

## Interpretation

The findings are consistent with the absence of statistically significant serial dependence in the sample. Within the limitations of the selected data and testing framework, the results therefore do not provide evidence against weak-form market efficiency.
